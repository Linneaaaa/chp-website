产品更新区突出 PDF 11、12、27、31、32、36、66、67、68、70、71、73 页。它表示相对旧网站的图片/展示更新，不保证每个出现的型号都是首次研发的新型号。原有对应型号可能已出现在其他套系中。

新版未单列旧网站的洗护瓶系列，因此该分类与其旧图继续保留。其他有旧图的系列提供“查看往期产品图片”切换，不删除历史资产。图片中规格可能更新，因此当前默认展示新版，往期图片明确标为 Archive。

部分 PDF 字体编码不能完整提取中文/型号，所有规格保留在原始表格图中，不根据乱码重建数据。例如 PDF 70 页型号为 PETG440-50ML，表格容量为 57；网站不擅自把两者统一。

## 内容维护

- `js/catalogue-data.js`：真实 PDF 路径、2026 各系列页码、更新区选图、旧版图片清单。
- `images/products/2026/pdf-NN.jpg`：整页产品图和规格表。
- `images/products/2026/photo-NN.jpg`：从相同页渲染图裁出的照片，只用于更新卡片。
- `CATALOGUE_2026.products`：可选的逐型号结构化记录。仅将已核实型号、材质、容量等填入，`published: true` 才展示。当前以完整手册页面呈现，未重复录入可能歧义的数字。
- `admin/` 仍是浏览器本地草稿后台，不会自动更新公开网站。

更换手册时上传真实文件并更新路径，再同步页码、产品页图片和照片。不要只更换 PDF 而让图片继续使用旧表格。下载代码检查 HTTP 状态与 PDF 文件头，遇到错误响应不会生成伪 PDF。

## 验证与发布

1. 网站根目录为仓库内 `chp-website/`，没有构建依赖。
2. 执行 `node check-catalogue.cjs` 验证下载分支、原 PDF、60 张新版产品页、旧图片路径和翻译。
3. 本地 HTTP 预览检查桌面/手机、系列筛选、图像放大、旧版切换、询价预选、四种语言。
4. 点击真实下载按钮，用 SHA-256 与用户原件比对；不能只检查按钮文字。
5. 沿用已连接的原 Vercel 项目。更新分支自动生成预览；合并到其生产分支后才更新正式网站。Vercel 根目录应与原成功部署一致，静态站点目录为 `chp-website`。
6. 发布后再次检查实际域名的下载、页码链接和图片。

回滚：还原本次更新提交并重新部署，保留历史资源。
