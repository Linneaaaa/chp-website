# 2026 产品内容与发布指南

## 当前状态

网站保持原有静态 HTML/CSS/JS、四种语言和 12 个既有系列。新增真空瓶 `s13`、尖嘴瓶 `s14`，以及首页手册入口、产品中心入口和新品展示区。

尚未收到 2026 手册和新品资料，因此没有添加产品规格、虚拟产品或 PDF 文件。下载按钮显示“PDF 即将上线”且禁用。两个新分类可筛选和打开，空状态提供询价入口。原有图片保留，未标记为 2026 新品。

公开内容源：`js/catalogue-data.js`。原后台 `admin/` 仅在浏览器 localStorage 保存草稿，不会同步公开网站；不要把在后台点击保存当作发布。

## 需要提供的资料

- 2026 完整产品手册 PDF（确认可公开下载）。
- 新增瓶款清单：型号、所属系列、容量、材质；有的话提供尺寸、瓶口规格与对应手册页码。
- 清晰产品图片，或允许从 PDF 提取图片；确认哪些是新增、哪些是旧款更新。
- 若以后提供旧版 PDF，请说明是否保留旧版入口。当前仓库没有旧 PDF，未删除任何旧手册。

## 接入真实 PDF

1. 将实际文件放到 `downloads/CHP-2026-Product-Catalogue.pdf`（目录需新建）。
2. 在 `js/catalogue-data.js` 将 `pdfPath: null` 改为 `pdfPath: 'downloads/CHP-2026-Product-Catalogue.pdf'`。
3. 保持文件名为英文字母、数字、连字符或下划线，扩展名 `.pdf`。`downloadName` 是客户下载后的文件名。
4. 点击按钮核对完整 PDF。下载前检查 HTTP 状态与 `%PDF-` 文件头；404、HTML 错误页、网络失败或超时会显示错误，不下载冒充 PDF 的文件。

## 添加核实过的新品

在 `CATALOGUE_2026.products` 数组中添加对象，字段如下。这里只说明字段，不提供虚构样品：

| 字段 | 内容 |
| --- | --- |
| `published` | 核实后设为 `true`，草稿为 `false` |
| `series` | 现有系列 `s01`–`s12` 或真空瓶 `s13` / 尖嘴瓶 `s14` |
| `model` | 手册中的真实型号（必填） |
| `image` | 已上传图片的相对路径，如 `images/products/2026/实际文件名.png` |
| `capacity` | 已确认的容量及单位；未知时省略 |
| `material` | 已确认的材质；未知时省略 |
| `dimensions` | 已确认的尺寸及单位；未知时省略 |
| `neckFinish` | 已确认的瓶口规格；未知时省略 |

只有 `published: true`、非空型号、有效系列的记录才展示。记录同时进入新品区和所属系列，询价按钮会预选型号。字段按纯文本渲染，不支持 HTML。缺图不会生成假图片，加载失败显示“图片即将上线”。新增产品可以归入任意旧系列，不局限于新系列。

`LEGACY_GALLERY_IMAGES` 列出原有手册图片。更新旧款时保留必要的旧内容，按确认清单替换相应图片，不要把全部旧图片标为新品。

## 验证与部署

仓库根目录下的 `chp-website/` 才是站点根目录。无构建依赖、无 package.json、无仓库内部署工作流。README 原部署方式为 Vercel，检查时 GitHub 的 main 提交状态有 Vercel 部署成功记录；域名和 Vercel 项目设置需在原项目确认。

1. 本地从站点目录运行 `python -m http.server 8765`，访问 `http://localhost:8765`，不要用文件模式验证下载。
2. 检查桌面/手机布局、四种语言、新系列筛选、空状态、原图片画廊和询价入口。缺资料时应没有 PDF 请求。
3. 接入 PDF 后检查真实下载并打开内容；故意使用不存在的文件名，确认显示错误而不是下载错误页，再恢复正确路径。
4. 接入产品后核对图片、规格、系列、询价型号与手册一致。
5. 将更新分支合并到原 Vercel 项目配置的生产分支（原仓库为 `main`），等待 Vercel 自动部署。保留原项目与域名；静态项目根目录应为 `chp-website`，无需构建命令。若现有设置不同，先核对原成功部署，不直接重建项目。
6. 在实际域名再次验证页面和下载。未收到真实 PDF 前只能验证缺失/失败保护和测试数据流程，不能宣称真实手册下载已验收。

回滚：还原此次提交并让原 Vercel 项目重新部署，不删除旧资产。
